# Northordo

Northordo — локальная веб-система для управления ремонтными объектами, работами, сметами, финансами, материалами, инструментами и документами. Проект рассчитан на небольшую команду и находится на ранней стадии разработки.

Исходный код открыт. Рабочие данные, учётные записи, пароли, база и прикреплённые документы в репозиторий не входят.

## Возможности

- **Обзор:** финансовая сводка компании и отдельных объектов, прогноз по внесённым планам. Порядок платежей внутри дня неизвестен. Показатель объекта отражает разницу его операций, а не выделенный остаток денег компании.
- **Объекты:** карточки с заказчиком, статусом и сроками, история изменений, мягкое удаление и восстановление.
- **Работы:** предстоящие и выполненные задачи с объектом, сроком и примечанием.
- **Сметы:** позиции, версии и серверный расчёт стоимости; калькулятор количества, длины, площади, периметра, объёма, площади стен и ограниченных формул.
- **Финансы:** поступления и расходы, общий бюджет на период, планы платежей и прогноз кассового разрыва. При проведении плана создаётся связанная фактическая операция. Если платёж внесён отдельно вручную, отмените соответствующий план, чтобы избежать двойного учёта.
- **Материалы:** список «Нужно купить» и «Куплено» с количеством и привязкой к объекту. Галочка отмечает покупку; денежный расход записывается отдельно в финансах.
- **Инструменты:** тип, состояние, статус, местонахождение, ответственный и история.
- **Документы:** локальные вложения, категории, привязка к объекту, скачивание и архив. Разрешены PDF, TXT, DOC/DOCX, XLS/XLSX, JPG/JPEG, PNG и WEBP до 10 МиБ.

Есть роли OWNER и ADMIN; защищённые серверные маршруты проверяют сессию и роль. Управление пользователями через интерфейс, резервирование и готовый доступ через интернет пока не реализованы.

## Технологии и требования

Windows, Node.js 26 (проверенная версия), npm, PostgreSQL и Git. Клиент: React, TypeScript и Vite. API: Fastify. База: PostgreSQL.

Ниже команды для **PowerShell**. Выполняйте их в папке проекта. Используйте `npm.cmd`, если выполнение `npm.ps1` запрещено политикой PowerShell.

## Установка

### 1. Получить проект и зависимости

```powershell
git clone https://github.com/dikaya-rechka/Northordo.git
cd Northordo
npm.cmd ci
```

### 2. Создать локальную базу PostgreSQL

Установите и запустите PostgreSQL, оставив базу доступной только на локальном компьютере. Откройте SQL Shell (psql) или запустите `psql` в PowerShell от имени администратора PostgreSQL:

```powershell
psql -U postgres -d postgres -h 127.0.0.1
```

Если `psql` не найден, запустите SQL Shell (psql) из меню «Пуск» либо укажите полный путь к `psql.exe` в папке `bin` установленного PostgreSQL.

Внутри `psql` выполните:

```sql
CREATE ROLE northordo_app LOGIN;
\password northordo_app
CREATE DATABASE northordo OWNER northordo_app;
```

Команда `\password` отдельно запросит пароль роли. Затем выйдите командой `\q`. Эти команды создают новую пустую базу; не запускайте их повторно поверх существующей базы.

### 3. Настроить соединение

В PowerShell скопируйте пример настройки и откройте его в редакторе:

```powershell
Copy-Item server/.env.example server/.env
code server/.env
```

Укажите пароль роли `northordo_app` в `PGPASSWORD`. Остальные значения в примере соответствуют командам выше. Файл `server/.env` содержит секрет и исключён из Git; не публикуйте его.

### 4. Создать таблицы и владельца

```powershell
npm.cmd run db:migrate
npm.cmd run setup:owner
```

Миграции создают структуру в пустой базе, но не загружают рабочие данные. Настройка OWNER запросит имя пользователя и пароль дважды; ввод пароля скрыт. OWNER можно создать этой командой только при пустой таблице пользователей. Используйте отдельный пароль приложения длиной 12–128 символов.

### 5. Запустить приложение

В первом окне PowerShell:

```powershell
npm.cmd run dev:api
```

Оставьте окно открытым. Во втором окне PowerShell, в той же папке:

```powershell
npm.cmd run dev
```

Откройте адрес, напечатанный Vite: обычно [http://127.0.0.1:5173/](http://127.0.0.1:5173/). Не открывайте `index.html` напрямую из проводника. Проверка API: [http://127.0.0.1:5173/api/health](http://127.0.0.1:5173/api/health).

## Ежедневное использование

1. Создайте объект и при необходимости добавьте смету и работы.
2. В «Финансах» внесите фактические операции, бюджет и ожидаемые платежи. Если деньги были до начала учёта, можно указать начальный остаток; без него остаток считается по всем внесённым операциям.
3. В «Материалах» добавьте нужный материал и отметьте его галочкой после покупки.
4. Добавьте инструмент и при необходимости прикрепите документ к объекту.
5. В «Обзоре» переключайтесь между компанией и объектами. Прогноз зависит от полноты данных и не заменяет проверку реального банковского остатка.

## Данные и безопасность

- Фактические данные хранятся в локальной PostgreSQL. Схема создаётся миграциями из `database/migrations/`; содержимого базы в репозитории нет.
- Копии вложений хранятся вне проекта, по умолчанию в `%LOCALAPPDATA%/Northordo/documents`. Параметр `NORTHORDO_DOCUMENT_ROOT` задаёт другой абсолютный путь вне проекта.
- Пароли и локальные настройки не входят в репозиторий. Не добавляйте реальные документы, дампы базы и другие рабочие данные в Git.
- Публикация кода **не открывает приложение в интернет**. API и Vite привязаны к `127.0.0.1`. Перед удалённым доступом нужны отдельные решения по HTTPS/VPN, защите хоста, правам и проверке безопасности. Не открывайте базу и dev-сервер в интернет.
- Автоматического резервирования и проверенного восстановления пока нет. Для полноценной копии понадобятся и база данных, и папка вложений. До внедрения и проверки восстановления рекомендуется использовать вымышленные данные.

## Команды разработки

```powershell
npm.cmd run build          # проверка типов клиента и сборка
npm.cmd run typecheck:api  # проверка типов сервера
npm.cmd run lint           # статический анализ
```

`src/features/` содержит пользовательские модули, `server/src/modules/` — серверные маршруты, `database/migrations/` — схему, `docs/` — описание решений. Подробности и ограничения: [архитектура](docs/architecture.md). Правила проекта: [AGENTS.md](AGENTS.md).
